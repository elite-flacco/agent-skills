# Evaluation Checklist

## Hard Requirements

- [ ] The review scope is explicit.
- [ ] Every scored skill was read in full or assigned to a narrow subagent batch with exact files.
- [ ] Every finding includes evidence, not only opinion.
- [ ] Subagent batches are deduplicated so one parent task cannot inflate pattern strength.
- [ ] Recommendations include concrete names and trigger criteria.
- [ ] New skills, hooks, scripts, or automations are recommended only for repeated reusable patterns.
- [ ] If no artifact is warranted, the report says so directly.
- [ ] Runtime-specific findings distinguish intentional runtime specificity from stale assumptions.

## Quality Checks

- [ ] The report leads with decisions and highest-value findings.
- [ ] Mechanical hygiene issues are separated from subjective quality judgments.
- [ ] Existing skills are preferred over new artifacts when they can absorb the fix cleanly.
- [ ] Verification commands and results are included.
- [ ] The output is concise enough to act on without rereading every reviewed skill.
